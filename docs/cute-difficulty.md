# 아기자기 난이도 구성

2026-10-29 기준. 홈 → 게임 시작 → 난이도 선택 → 문제 목록 → 게임 → 완료 순서다. 쉬움·보통·어려움은 처음부터 자유롭게 선택하고 시간·실수 제한이나 자동 난이도 상승은 없다. 기존 광고 공간과 게임 기하·판정을 유지한다.

| 단계 | 콘텐츠 | 획 수 | 초기 자유 획 | 막힘 관계 수 | 최대 의존 깊이 |
| --- | --- | --- | --- | --- | --- |
| 쉬움 | 아이·오이·우유·아기·오리·여우·공·콩·양·용 | 3~5 | 2~4 | 0~3 | 1~3 |
| 보통 | 성공적 (대표 1문제) | 13 | 4 | 19 | 5 |
| 어려움 | 우리가 저마다 / 힘에겨운 (대표 1문제) | 37 | 14 | 82 | 11 |

이름만 바꾸지 않고 실제 head ray와 본체 사이의 의존 관계를 비교했다. A의 제거를 막는 B가 있으면 A→B 간선으로 세며, 자유 노드를 동시에 제거하는 층 수를 의존 깊이로 기록했다. 깊이는 최소 클릭 수나 이용자의 체감 난이도 점수가 아니다. 쉬움 중 콩은 깊이 3으로 나머지보다 순서 생각이 조금 더 필요하다. 쉬움의 기존 문제 순서는 유지한다.

보통·어려움은 승인된 실제 폰트 퍼즐을 재사용한 비교용 첫 구성이다. 모든 획에서 고정 장애물에 의한 영구 막힘이 없고 의존 그래프에 순환이 없음을 테스트한다. 고정 ray와 남아 있는 본체 관계가 동일하므로 모든 합법 제거 순서가 완료 가능하다. 실제 난이도 평가는 사용자 플레이 확인 후 조정한다.

난이도별 완료 표시는 현재 아기자기 세션의 메모리 상태다. 다른 난이도로 이동하거나 문제 목록으로 돌아와도 유지한다. 다시 풀어도 중복 집계하지 않는다. 홈으로 나가거나 새로고침하면 초기화하며 영구 저장은 하지 않는다. 마지막 문제는 같은 난이도의 목록으로 돌아가고 다른 난이도로 자동 이동하지 않는다.

구현: game/cute-courses.ts가 단계별 콘텐츠를 관리하고 EasyCourse.tsx가 선택·목록·현재 문제·완료 상태를 관리한다. Game과 CompletionCard는 공통 풀이·완료 동작을 유지한다. 모던·여유는 기존 문장 퍼즐을 유지한다.

## 한 줄 최대 4글자 디자인 비교 (2026-10-29)

어려움 목록에서 기존 2줄과 3줄(우리가 / 저마다 / 힘에겨운)을 정적으로 비교한다. 같은 화면 너비에서 글자·화살표가 약 49% 커지고 세로 길이가 늘어난다. 새 배치는 기존 방향의 ray가 고정 원형에 막히므로 플레이용이 아니다. 실제 플레이는 기존 문제를 유지하고, 디자인 확정 후 해당 배치에 맞춰 출제 문제를 다시 만든다. 비교 자료: docs/design/four-letter-comparison-mobile.png.

# 아기자기 화면 구성

홈 → 게임 → 완료 화면을 아기자기의 기준 흐름으로 구성한다. 나머지 분위기의 화면을 확장할 때 정보와 행동의 순서를 재사용하고 색·글자·모서리·안내 문구를 바꿀 수 있다. 이번 변경은 새 문제나 점수·난이도 진행을 추가하지 않는다.

## 홈

제목/캐릭터 → 분위기 선택 → 선택한 분위기 안내 → 접을 수 있는 놀이 방법 → 게임 시작 순서다. PC는 제목과 캐릭터를 나란히 배치하고 모바일은 세로로 배치한다. `어떻게 구하나요?`는 방향 확인, 막히면 다른 획 선택, 모두 제거하면 구출 완료의 세 단계만 안내한다. 퍼즐의 정답을 알려 주는 힌트 기능은 아니다.

## 게임

홈 이동/분위기 표시 → 게임 제목과 초대 문구 → 현재 문장 → 기다리는 친구/남은 획 → 퍼즐 → 피드백 → 다시 시작 순서다.

`GameProgress`는 실제 removed.length만 사용한다. 애니메이션이 끝나 상태에서 삭제된 획만 진행에 반영하며 막힌 시도는 획 수를 줄이지 않는다. 남은 획과 progressbar는 같은 값을 표시한다. 기다리는 친구 수는 현재 퍼즐의 고정 대상 수이며 개별 구출/점수로 표현하지 않는다.

퍼즐 본체·클릭·방향·충돌·줄 뽑기·붉은 복귀 동작은 기존 규칙 그대로다. 현재 검수용 문구 ‘우리가 저마다 / 힘에겨운’도 그대로 사용한다.

## 완료

마지막 획 제거 → 기존 ㅇ들의 모임/손잡기/퇴장 → 완료 카드 순서다. `RescueParade`가 실제 gone 단계에 도달했을 때만 `onFinished`를 알리고 `CompletionCard`로 바꾼다. 연출 도중에는 결과 카드로 덮지 않는다. reduced motion에서도 동일한 완료 상태로 이어진다.

완료 카드는 친구들 그림, ‘모두 함께 탈출했어요!’, 실제 구출 친구 수, 다음 두 행동을 표시한다.

- 다시 시작: 같은 퍼즐과 진행 표시·모든 연출 상태를 초기화한다.
- 다른 분위기 고르기: 홈으로 돌아간다. 선택한 분위기는 유지하고 새 게임 시작 시 퍼즐을 초기화한다.

새 콘텐츠가 없으므로 다음 문제/힌트/점수/보상 버튼은 넣지 않는다. 완료 제목에 키보드 초점을 옮겨 새 화면을 인지할 수 있게 한다.

## 구현 경계

`CuteScreens.tsx`는 표시용 `PlayGuide`, `GameProgress`, `CompletionCard`를 소유한다. 게임 상태는 Game에 남긴다. 현재 이 화면 구성은 아기자기에만 적용하며 모던/여유는 이전 화면 구성을 유지한다. 스타일은 cute-home 및 아기자기 범위로 제한한다. 향후 동일한 정보 순서를 다른 분위기에 적용할 수 있다.

브라우저 검사는 실제 클릭/터치 전체 풀이, 진행 수 변경, 구출 연출 후 완료 전환, 재시작, 완료에서 홈/재진입을 확인한다. 신규 시각 변경에 별도 게임 규칙을 만들지 않는다.

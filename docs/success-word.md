# 성공적 플레이 퍼즐 (2026-10-28)

현재 홈의 게임 시작 버튼은 `success-puzzle.ts`의 ‘성공적’을 연다. 이전 ‘성’ 자료는 참고/회귀용으로 남기며, 이번 규칙은 이전 평행 이동 설계보다 우선한다.

- 원본: 저장된 Noto Sans KR Regular 2.004, SIL OFL 1.1. 외곽과 자모 비율은 실제 글리프에서 가져왔다. 원본 OTF·라이선스·해시는 `apps/web/scripts/font-source`에 있다.
- 필획: 성 4개(ㅅ 2 + ㅓ 2), 공 3개(ㄱ 1 + ㅗ 2), 적 6개(ㅈ 3 + ㅓ 2 + ㄱ 1). 한 자모 최대 3개다. 범용 자동 필획 추출기는 아니다.
- 실제 연결부만 분리한다. ㅅ/ㅈ의 내부 접점에서 외부 곡선의 지정 접점까지 경계를 공유하고, 원본 외부 Bézier 곡선은 De Casteljau로 그대로 나눈다. 가짜 연결 획, 사각형 영역 잘라내기, 충돌 예외를 쓰지 않는다. 몸통 Path와 충돌 Path는 동일하다.
- 두 ㅇ은 원본 폰트의 타원형 받침 윤곽에 기존 얼굴/색상을 적용했다. 고정 장애물은 외부 곡선 안쪽 전체로, 구멍까지 막는다. 표시용 내부 구멍과 장애물 윤곽을 구분한다.
- 획 안쪽의 작은 노란 화살촉과 본체 색상은 `wordStrokeColors`에서 관리한다. 끝단 안쪽의 표식이므로 원래 글자 외곽을 확장하지 않는다. 각 표식의 세 꼭짓점이 해당 몸통 내부에 있는지 검사한다.

## 막힘과 풀이 검증

활성 게임은 `findHeadBlocker`를 사용한다. 표식 끝에서 명시된 벡터 방향으로 보드 경계까지 뻗는 선분과 다른 몸통/고정 장애물의 실제 도형을 검사한다. 다른 화살촉, 자신의 몸통, 획 전체의 가상 평행 이동은 검사하지 않는다. 접촉은 막힘이다. 곡선 근사는 기존 논리 오차 .025를 재사용한다.

정지한 획의 위치·표식·벡터·고정 장애물은 제거 순서에 따라 바뀌지 않는다. 따라서 각 획의 막는 획 집합은 고정이고, 제거 시 그 집합에서 해당 획만 빠진다. 현재 13개 획의 모든 도달 가능한 부분집합을 탐색해 합법적 선택 후 막다른 상태가 없는지 검증한다. 작은 부분집합 전수 및 큰 부분집합 표본에서 그래프와 실제 기하 질의도 비교한다. 플레이 코드는 정답 목록을 사용하지 않는다.

새 받침 ㄱ은 오른쪽 아래 끝에서 아래로 당긴다. 왼쪽으로 당기면 앞 글자의 고정 ㅇ에 영구히 막히므로 그 방향을 데이터로 채택하지 않았다. 기존 성의 위/왼쪽 위 방향은 유지했다.

기존 `findBlocker`의 평행 이동 질의와 옛 `firstPuzzle` 데이터는 이전 엔진/템플릿 회귀 테스트용이다. 현재 `Game`에서는 호출하지 않는다.

## 줄 뽑기

각 획은 꼬리→당기는 끝 순서의 별도 writing spine을 갖는다. `rope.ts`는 경로를 길이별로 계산하여 소비한 길이부터 남은 경로를 반환한다. `PullStroke.tsx`는 고정된 원본 본체에 SVG mask를 적용해 꼬리부터 비우고, 출구부터 직선으로 나온 줄을 이어 그린다. 바깥으로 나온 길이와 안에 남은 길이의 합은 원래 줄 길이다. 화살촉은 지정된 방향으로만 움직이고, 평평한 줄 끝의 안쪽 여백을 유지한다. 그룹 전체에는 이동 transform을 적용하지 않는다.

퇴장은 1100ms이며 완료 후에만 상태에서 삭제한다. 애니메이션 도중의 충돌은 검사하지 않는다. 재시작/홈 복귀 시 타이머와 animation frame을 정리한다.

현재 세 글자의 직선/꺾임/곡선은 검수했지만, 자기 근접·교차가 심한 나선형의 가변 굵기 mask는 추가 시각 검수가 필요하다. 이 콘텐츠에 없는 도형까지 완성됐다고 간주하지 않는다.

실제 스마트폰 및 설치/오프라인 업데이트는 별도 확인 사항이다. 서버·저장·점수·광고·새 난이도 화면은 추가하지 않았다.

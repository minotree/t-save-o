# 우리가 저마다 / 힘에겨운 (2026-10-28)

현재 플레이 콘텐츠는 첫 줄 `우리가 저마다`, 둘째 줄 `힘에겨운`이다. 사용자 변경 요청으로 이전 공격적/수비적 작업을 대체했다. 글자 열 개, 이동 획 37개, 고정 구출 대상 네 개(우·힘의 ㅎ 내부·에·운)다.

## 글자와 입력

`phrase-puzzle.ts`가 저장된 Noto Sans KR Regular 2.004의 실제 글리프 외곽을 정의한다. 라이선스는 기존 SIL OFL 1.1, 출처와 원본은 scripts/font-source를 유지한다. 게임에서는 폰트를 내려받지 않고 SVG 윤곽만 쓴다. 가독성 시안대로 외곽을 늘이지 않고 작은 노란 화살촉을 본체 안쪽에 표시한다.

`assembleGlyphPuzzle`은 단일 배율 .29로 위치만 조합한다. 첫 줄의 공백은 실제 글자 간 간격으로 남긴다. 둘째 줄은 첫 줄과의 고정 장애물 경로를 고려한 고정 위치에 둔다. 글자 모양은 조각별로 늘이거나 찌그러뜨리지 않는다.

분할은 실제 연결부에서 이루어진다. ㄹ은 세 조각, ㅈ은 세 조각, ㅁ은 ㄴ/ㄱ 형태 두 조각이다. 겨의 ㅕ는 위 세로획과 윗 가로획을 연결된 ㄴ 형태 한 조각으로 유지하고 아래 세로획/가로획을 각각 분리하여 총 세 조각이다. 가짜 연결선이나 충돌 제외 규칙을 추가하지 않는다. 모든 자모는 최대 세 이동 조각이며 고정 원형은 별도다. 에의 원형과 연결 가로획은 원본의 실제 접합부에서 구분한다.

각 조각은 본체 Path, 꼬리→출구 spine, 내부 화살촉, 명시적 이동 벡터를 갖는다. 곡선의 양쪽 윤곽은 원본을 유지하며 경로 전체를 하나의 도형으로 제거한다. 다른 글자/난이도를 자동 생성하는 범용 폰트 필획 추출기는 아니다.

화살촉 표시에는 `readableHead`를 적용한다. 원본의 팁 좌표를 그대로 두고 뒤쪽으로 길이를 최대 2.1배, 너비를 최대 1.85배 늘린다. 테두리 .6 논리 단위 여유와 삼각형 내부 격자를 검사해 본체 밖으로 나가지 않는 크기를 선택한다. 진한 1 논리 단위 테두리는 붉은 피드백 중에도 표식을 구분한다. 이는 표시 전용이며 저장된 Arrow/head 데이터와 충돌 ray 원점/방향은 변경하지 않는다. 정적 표시 형상은 useMemo로 캐시해 매 애니메이션 프레임에 다시 계산하지 않는다.

가로 스크롤은 사용하지 않는다. 세 분위기 모두 SVG 전체를 화면 너비에 맞춰 두 줄을 함께 표시한다. 이전 강제 최소 폭과 스크롤 안내는 제거했다. 클릭 영역은 실제 채워진 본체를 따른다. 이전 확대 투명 획의 클릭 영역이 인접 조각을 가로채던 문제를 수정했다. 키보드 초점과 Enter/Space 선택도 유지한다.

## 막힘을 보여주는 왕복 동작

`findHeadContact`가 화살촉 끝에서 보드 경계까지의 전방 직선을 검사하고 **가장 가까운** 실제 몸통/고정 장애물 접촉점과 거리를 반환한다. 입력 배열의 순서로 장애물을 고르지 않는다. 몸통 외곽은 기존 compileShape와 .025 논리 단위 곡선 근사를 재사용한다. 화살촉 자체, 자기 몸통, 가상 평행 이동 도형은 장애물에서 제외한다.

막힌 경우 `Game`의 attempt 상태로 들어간다. 900ms 동안 `bumpProgress`로 접근(0~42%) → 접촉 유지(42~56%) → 복귀(56~100%)한다. 이동량은 실제 접촉 거리 이하이며, 원래 줄 뽑기와 동일한 mask/바깥 줄/화살촉 구조를 사용한다. 장애물은 움직이지 않는다. 바깥 줄이 접촉 지점을 지나 그려지지 않도록 제한한다. 시작부터 접촉한 경우 거리 0으로 처리하며 가짜 이동 간격을 만들지 않는다.

접촉 순간(왕복 시간의 42% 지점)부터 코랄색으로 표시하고 붉은 상태로 복귀한다. 원래 자리로 돌아온 후 기존 경고를 표시하고 1400ms 더 유지한 뒤 원래 색으로 복원한다. 처음부터 접촉한 거리 0의 획은 즉시 붉어진다. 획은 제거되지 않는다. 이동/왕복 중 다른 획의 선택을 잠시 막고 재시작/홈 복귀 시 timeout과 RAF를 정리한다. 성공 제거는 800ms 줄 뽑기를 사용한다 (2026-10-29 사용자 피드백으로 1100ms에서 단축). 모든 난이도·분위기에 동일 적용한다.

## 완료 후 친구들 퇴장

`RescueFriends.tsx`는 플레이 중 기존 원본 ㅇ 윤곽/얼굴을 그대로 표시한다. 모든 획이 제거된 뒤에만 `RescueParade`를 마운트한다. 1000ms 동안 가운데로 모이고, 450ms 동안 손발을 내밀고, 손을 잡은 상태를 600ms 유지한 뒤 2000ms 동안 다리를 번갈아 움직이며 오른쪽으로 퇴장한다. 전체 연출은 4050ms다. 인접 캐릭터의 손 끝은 동일한 좌표이며 함께 움직이므로 퇴장 중에도 손이 연결된다. 원래의 타원/원형 비율은 유지하면서 모일 때 크기를 맞춘다.

모바일에서도 퍼즐 전체가 보이므로 완료 시 수평 스크롤을 수행하지 않는다. 퇴장 후 성공 문구와 다시 시작 버튼은 남는다. 다시 시작/홈 복귀 시 연출 컴포넌트의 RAF를 해제하고 원래 위치의 고정 대상 네 개로 복원한다. 시스템의 reduced motion 설정에서는 긴 이동을 생략한다. 이 연출은 완료 후 표시만 변경하며 플레이 중의 충돌/고정 장애물/구출 판정은 변경하지 않는다.

## 풀이와 검증

고정된 전방 ray와 몸통들의 의존 그래프가 순환하지 않고 고정 장애물에 영구히 막히는 획이 없음을 검사한다. 모든 비어 있지 않은 DAG의 유도 부분그래프에는 자유 노드가 있으므로 어떤 합법적 제거 순서를 선택해도 막다른 상태가 생기지 않는다. 작은 보드 64개 부분집합에서 그래프와 실제 기하 질의를 비교한다. 게임에는 정답 순서가 없다.

```powershell
pnpm.cmd dev:web
pnpm.cmd typecheck
pnpm.cmd test
pnpm.cmd --filter @t-save-o/web test:e2e
pnpm.cmd build
node docs/design/verify-phrase-glyphs.mjs
```

마지막 검사는 실행 중인 Vite와 로컬 Chrome을 사용한다. 원본 OTF와 본체 합집합을 글자당 16,625개 점에서 비교한다. 표본 비교이며 곡선 전체의 기호적 동일성 증명은 아니다. 브라우저 테스트는 실제 클릭/터치 에뮬레이션, 전체 37개 제거, 네 ㅇ 구출, 접촉 거리 도달/복귀 후 경고 순서, 왕복 중 재시작을 확인한다. 실제 스마트폰 검증은 별도다.

예전 성공적 데이터는 회귀 테스트용이다. 활성 화면은 `createPhrasePuzzle`을 사용한다. 서버·광고·점수·저장 기능은 추가하지 않는다.

# 실제 폰트 기반 ‘성’ 적용 (2026-10-28)

## 출처와 라이선스

Noto Sans KR Regular 2.004의 완성형 성(U+C131), glyph ID 15741을 사용했다. [공식 OTF 파일](https://github.com/notofonts/noto-cjk/blob/main/Sans/SubsetOTF/KR/NotoSansKR-Regular.otf)과 [공식 SIL OFL 1.1](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE)을 확인했다. OFL의 사용·수정·재배포 허용 조항에 따라 상업적 게임에서 사용할 수 있는 폰트를 선택했다. 원본 파일 내부 저작권은 © 2014-2021 Adobe다.

원본은 apps/web/scripts/font-source에 수정 없이 보관하고 OFL 전문과 출처/버전/SHA256을 함께 기록했다. SHA256은 `69975a0ac8472717870aefeab0a4d52739308d90856b9955313b2ad5e0148d68`이다. 추출 자산의 고지는 public/review/NotoSansKR-OFL.txt로 배포물에도 포함한다. 폰트 원본은 개발용이며 dist에는 들어가지 않는다.

## 추출·분할

`pnpm.cmd --filter @t-save-o/web glyph:seong`은 개발용 OpenType.js 2.0.0(MIT)와 Paper.js 0.16.0(MIT)으로 실행한다. 두 라이브러리는 앱 런타임에 추가되지 않는다. 폰트 해시나 예상 글리프/윤곽 소유권이 달라지면 재검토를 요구하며 조용히 다른 소스를 쓰지 않는다.

1. 완성형 ‘성’의 원래 바깥/안쪽 ㅇ 윤곽, ㅅ, ㅓ를 추출한다. 자모 단독 글리프를 다시 조합하지 않는다.
2. 원본 bbox (49,-827)~(797,76)에 대해 단일 배율 `190/903`과 평행 이동을 적용한다. 모든 제어점·획·원본 비교 화면이 같은 변환을 사용한다. 자모별 가로/세로 늘이기나 독립 위치 보정은 없다.
3. ㅅ은 기존 왼쪽 이동 벡터 (44,-67.08)와 평행한 분리선을 사용한다. 원본 안쪽 접점 (321,-538)을 기준으로 법선 방향 3 논리 단위 떨어진 위치에 폭 1.2의 실제 절삭 간격을 둔다. 처음 접점 그대로 절삭하면 떨어진 작은 섬이 생겨 연결성 검사에서 탈락했으므로 분리선 위치를 조정했다. 최종 두 조각은 각각 연결된 하나의 도형이다.
4. ㅓ의 세로획은 원본 x=711~794 영역 그대로 보존한다. 가로획의 연결 끝만 x=711에서 1.2 논리 단위만큼 짧게 절삭한다. 표시만 떨어뜨리거나 충돌만 무시하지 않는다.
5. 원본 곡선은 Paper의 Bézier Boolean 연산으로 유지하고, M/L/C/Z 명령으로 내보낸다. 좌표 반올림은 1e-8 논리 단위다. 움직이는 획 면적의 99.287369%를 보존하고, 약 0.712631%는 두 접점의 분리를 위해 제거했다. 원본과 완전히 동일하다고 표현하지 않는다.
6. `seong-font.generated.ts`에 원본 전체 Path, 네 조각의 Path·부착점·이동 벡터·출처·분리 기준·면적을 기록한다. 이 파일의 좌표를 직접 편집하지 않는다. 동일 명령 재생성 시 자산과 비교 SVG의 SHA256이 동일함을 확인했다.

## 기존 엔진 연결과 유지 사항

`font-seong.ts`는 네 윤곽을 기존 instantiateTemplate(fill=true, strokeWidth=0)에 넣는다. 분할 상한은 ㅅ 두 조각·ㅓ 두 조각을 각각 검사한다. Path는 이미 공통 글리프 좌표에 있으므로 기존 자모 영역으로 다시 변형하지 않는다.

네 실제 이동 벡터는 이전 값 `(44,-67.08)`, `(-34.1,-49.88)`, `(0,-0.96)`, `(-0.48,0)`을 유지한다. 화살촉도 이 벡터를 표시한다. 게임의 Game.tsx·main.tsx·CSS, engine.ts·vector-shape.ts·jamo-templates.ts는 작업 전후 SHA256이 같음을 확인했다. 충돌 예외·정답 순서 하드코딩·경고/구출 규칙 변경은 없다.

ㅇ은 기존 원형 구출 캐릭터를 유지한다. 반지름 33.7, 테두리 6.2, 얼굴/색상과 원판 충돌은 동일하고 중심은 원본 글리프의 받침 중심으로 옮겼다. 원본 Noto Sans KR의 받침 ㅇ은 가로로 넓은 타원형이므로 비교 화면에서 이 차이를 명시한다.

## 비교와 검증

- 개발 서버 비교: http://127.0.0.1:5173/review/seong-font-comparison.html
- 벡터 자료: apps/web/public/review/seong-font-comparison.svg
- 브라우저 캡처: [seong-font-comparison.png](design/seong-font-comparison.png)

별도 비교 자료를 추가했으며 게임 홈이나 메뉴에는 추가하지 않았다. 왼쪽은 플랫폼 기본 폰트로 다시 쓴 텍스트가 아니라 추출한 실제 원본 글리프 Path다. 오른쪽은 게임에 넣은 네 Path와 원형 캐릭터다.

검사 결과:

- `pnpm.cmd typecheck`: 통과.
- `pnpm.cmd test`: 79개 통과. 원본 폰트 해시, 면적 보존, 원래 벡터, 연결성, 초기 비겹침, 왼쪽 선제거 가능·오른쪽 선제거 불가·왼쪽 제거 후 오른쪽 가능, 모든 합법 분기 완료를 포함한다.
- `pnpm.cmd --filter @t-save-o/web test:e2e`: 6개 통과. 데스크톱/모바일에서 기존 게임 동작 4개와 비교 자료 검사 2개다. 기존 game.spec.ts는 이번 작업에서 수정하지 않았다.
- `pnpm.cmd build`: 통과. 실제 폰트 파일과 개발용 추출 도구는 웹 배포물에 포함되지 않는다.
- `git diff --check`: 통과. 일부 기존 파일의 CRLF 정규화 알림은 오류가 아니다.

곡선 충돌은 기존 0.025 논리 단위 보수적 근사를 그대로 사용한다. 추가된 1.2 단위 분리 간격은 이 오차보다 충분히 크다. 브라우저 모바일 에뮬레이션까지 확인했으며 실제 스마트폰 가독성은 사용자 확인 대상이다. 커밋·푸시·배포는 수행하지 않았다.

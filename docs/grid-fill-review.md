# 모든 격자점을 사용하는 12×12 ‘성’ 검토판

2026-10-30 사용자 요구: 격자에 정렬하는 데 그치지 않고, ㅇ에 닿거나 내부에 있는 점을 제외한 모든 점을 화살표 경로로 사용한다. ㅅ·ㅈ·ㅊ의 사선도 포함한다.

## 이번 시안

- 개발 주소: `/grid-review.html`. 기존 첫 ‘아이’ 판은 유지하며 검토판을 별도 제공한다.
- 12×12=144점, ㅇ 내부/접촉 예외 16점, 나머지 128점을 정확히 한 번씩 사용. 누락/중복 0.
- 격자 피치 32·획 폭 8·외부 화살촉 18. 단순히 점의 근처를 지나가는 것을 사용으로 세지 않고, 실제 경로 중심선에 놓인 점만 집계한다. 격자 사이를 통과하는 교차도 금지한다.
- 한글은 직접 작성한 ㅅ 두 사선(분홍)·ㅓ 두 획(파랑)·고정 금색 ㅇ 하나. 실제 Noto 글리프를 분할한 데이터가 아니며 검토용이다. 총 25개 화살표(글자 4·검정 21)를 모두 제거해야 완료된다.
- ㅇ은 글자 4획이 제거되면 충돌에서 빠져 하단으로 내려가며, 검정 획까지 제거하면 퇴장한다. 기존 클릭/터치·막힘 왕복·이동 잠금·재시작을 재사용한다.
- 모든 화살촉 전방에 자기 몸통이 없다. 사선의 실제 몸통/화살촉과 ㅇ의 채워진 내부를 사용해 검사한다.
- ‘격자점 표시’를 켜면 초록 128점·회색 예외 16점을 확인할 수 있다. 표시 집계는 실제 정적 경로에서 계산한다. 이 집계는 초기 배치의 충족 여부이며 제거 중 남은 점 수가 아니다.
- 12×12는 이번 시안의 크기다. 초급 12×12·중급 20×20·고급 30×30 등은 사용자 예시이며 전체 난이도 규격 확정이나 다른 문제 개편을 뜻하지 않는다.

## 정적 데이터와 검증

- `apps/web/src/game/grid-review.generated.json`: 고정된 점 경로·ㅇ 예외 점·검증용 제거 순서. 실행 중 자동 출제하지 않는다. 제거 순서는 게임 판정에서 사용하지 않는다.
- `apps/web/scripts/generate-grid-review.py`: Python 표준 라이브러리만 사용하는 오프라인 저작 도구. `python apps/web/scripts/generate-grid-review.py`로 재생성한다. 현재 seed 526, 25경로·128점. 새 데이터는 아래 검사를 통과해야 한다.
- `grid-review.ts`: 동일한 실제 SVG 윤곽/충돌 형상으로 조립. 중심선의 사선 중간 격자점도 점 사용 집계에 포함한다.
- `grid-review.test.ts`: 144점 소유권/ㅇ 예외, 실제 사선, 셀 내부 교차 금지, 표시 화살촉 대 모든 몸통/ㅇ 겹침, 몸통 대 ㅇ 접촉, 자기 전방 미접촉, 실제 풀이 재생 및 모든 합법 순서의 의존 DAG를 검사한다.
- `grid-review.spec.ts`: PC/모바일에서 144점 표시(사용 128·예외 16)·가로 넘침·25개 화살촉 직접 클릭/터치·완료·재시작을 확인한다.
- Vite 다중 HTML 입력으로 운영 빌드에도 검토판 파일을 포함한다. 배포/실기기/설치 검증과 구분한다.

# 아기자기 보통·어려움 각 10문제 (2026-10-29)

사용자 요청으로 쉬움 10개를 유지하고 보통·어려움을 각각 10개로 확장했다. 모든 행은 공백 없이 최대 4글자다. 보통은 최대 2줄, 어려움은 최대 4줄이다. 기존 대표 문제는 각 단계 첫 문제로 보존한다. 모던·여유의 문제 구성은 이번 변경에서 늘리지 않는다.

기존에 검토한 실제 Noto Sans KR 글리프의 낱말을 조합한 디자인·플레이 확인용 문제다. 일부는 문장이 아닌 낱말 묶음이며 UI에서는 ‘오늘의 문제’라고 표시한다. 소재·문장과 난이도의 최종 확정은 디자인 검토 이후다.

보통은 8~18획, 어려움은 25~37획이다. 글자 수뿐 아니라 실제 막힘 관계로 각 문제의 고정 장애물 영구 막힘과 의존 순환이 없는지 검사한다. 한 줄에 최대 4글자를 유지하고 본문 세로 스크롤을 허용한다. 낱말 목록에는 원래 줄 구분을 표시한다. 완료 후 같은 단계의 다음 문제로 이동하며 마지막은 목록 복귀다. 완료 표시와 중복 집계 방지는 기존 세션 기준을 유지한다.

## 데이터와 재생성

- `course-content.ts`: 검토된 글리프 조합과 낱말 묶음, 정적 배치 데이터의 렌더링 조립.
- `course-layouts.generated.ts`: 추가 18문제의 행 순서·위치·행 간격·반대 끝을 사용하는 획 ID를 저장한다.
- `scripts/generate-cute-courses.mjs`: 개발 시 조합별 배치와 자연 끝 두 후보를 검토해 정적 데이터를 작성한다. 앱 실행 중에는 탐색·자동 출제·임의 방향 변경을 하지 않는다. 폰트 몸통이나 충돌 엔진을 바꾸지 않는다.
- `reverse-arrow.ts`: 반대 자연 끝을 쓰는 경우 본체는 보존하고 열린 M/L/Q/C spine·표식·벡터·안내를 함께 역전한다.

저장소 루트에서 `node apps/web/scripts/generate-cute-courses.mjs`로 재생성한다. 실패한 조합은 콘텐츠나 배치를 다시 작성하며 엔진 예외나 고정 대상을 통과하는 규칙을 추가하지 않는다. 재생성 후 단위·브라우저·빌드와 실제 화면을 확인한다.

진행 중인 문제가 고정된 데이터를 사용하며, 모임·손잡기·퇴장은 완료 후에만 실행한다. 최종 실제 기기의 터치·가독성 평가는 사용자 확인 대상이다.

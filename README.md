# t-save-o · ㅇ 구하기

한글 자모 화살표 획을 제거해 고정된 ㅇ을 구출하는 모바일 퍼즐 프로젝트다. 현재 ‘우리가 저마다 / 힘에겨운’ 두 줄의 37개 필획을 클릭·터치·키보드로 당겨 빼서 네 ㅇ을 구출한다. 실제 Noto Sans KR 윤곽과 획 안쪽의 노란 방향 표시를 사용한다. 막힌 획은 실제 장애물까지 전진했다 돌아온 후 경고한다. 저장·광고·원격 콘텐츠·자동 생성은 없다.

## 실행

Node 24.22.0 이상 24.x, pnpm 10.34.7을 사용한다. PowerShell 실행 정책에 영향받지 않도록 pnpm.cmd로 실행할 수 있다.

```powershell
pnpm.cmd install --frozen-lockfile
pnpm.cmd dev:web
```

개발 주소: http://127.0.0.1:5173 (포트 충돌 시 종료). 서비스 워커는 개발 서버에서 활성화하지 않는다.

```powershell
pnpm.cmd typecheck
pnpm.cmd test
pnpm.cmd build
pnpm.cmd preview:web
```

운영 빌드 미리보기: http://127.0.0.1:4173. 빌드 출력은 apps/web/dist다. 루트의 build/typecheck는 현재 존재하는 웹 앱을 검사한다. 별도 dev 별칭은 없다.

## 첫 퍼즐 플레이와 검사

홈 화면의 오렌지색 ‘게임 시작’ 버튼으로 첫 퍼즐에 진입한다. 홈으로 돌아가면 진행은 초기화된다. 홈과 퍼즐은 크림·오렌지·민트 팔레트를 사용하며, 막힌 화살표는 코랄색으로 표시한다.

홈에서 **아기자기 · 모던 · 여유**를 선택하면 화면 디자인과 획 색상이 바뀐다. 아기자기는 밝고 둥근 화면, 모던은 간결한 청회색 화면, 여유는 큰 글자·버튼과 선명한 대비를 사용한다. 모든 분위기는 현재 동일한 문제를 플레이한다. 연령 안내나 입력은 없다. 홈 왕복 시 분위기는 유지하고 퍼즐만 초기화한다. 단계별 문제·난이도 진행은 후속 작업이다.

아기자기는 홈의 접이식 놀이 방법, 게임의 실제 남은 획 표시, 구출 친구들의 퇴장 후 완료 카드를 제공한다. 완료 카드의 ‘다시 시작’은 같은 퍼즐을 복원하고 ‘다른 분위기 고르기’는 홈으로 돌아간다. 화면 순서와 공통화 기준은 [docs/cute-screen-pattern.md](docs/cute-screen-pattern.md)를 참고한다.

- 막힌 획은 가장 가까운 접촉점에 닿는 순간 코랄색이 되고 붉은 채로 원래 자리로 돌아온다. 복귀 후 경고와 함께 1.4초 유지한 뒤 원래 색으로 돌아온다. 제거되지 않으며 계속 풀 수 있다.
- 두 줄의 37개 이동 획을 모두 제거하면 네 ㅇ 구출 성공이다. 가능한 다른 제거 순서도 허용한다. 가로 스크롤 없이 퍼즐 전체를 화면 너비 안에 표시한다.
- 구출된 ㅇ들은 가운데로 모여 손발을 내밀고 손을 잡은 채 오른쪽으로 걸어 사라진다. 다시 시작하면 원래 배치로 복원한다.
- 막힘은 화살촉 앞쪽 직선만 검사한다. 제거 시 전체 도형을 평행 이동하지 않고 경로를 따라 꼬리부터 줄을 뽑는다. 현재 데이터·검증·이전 규칙과의 차이는 [docs/phrase-puzzle.md](docs/phrase-puzzle.md)를 참고한다.
- 다시 시작은 완료 후뿐 아니라 퇴장 애니메이션 중에도 초기 배치로 복원한다. 탭 키로 화살표에 초점을 맞추고 Enter/Space로 선택할 수 있다.
- pnpm.cmd test는 곡선 Path·실제 두께·윤곽/구멍·임의 방향의 연속 경로 충돌·자모 템플릿·분할 상한·고정 원판·ㅅ 의존 관계·모든 합법 제거 분기를 검사한다.
- pnpm.cmd --filter @t-save-o/web test:e2e는 설치된 Chrome을 사용해 데스크톱과 모바일 에뮬레이션에서 오답·퇴장·완료·재시작을 검사한다. 결과와 화면 캡처는 apps/web/test-results에 생성되며 Git에서 제외한다. 실제 스마트폰 검증과는 다르다.

현재 ‘성’은 실제 **Noto Sans KR Regular 2.004**의 완성형 글리프에서 분리한 네 윤곽을 사용한다. 원래 곡선·비율·획 두께를 유지하고 연결부에서만 1.2 논리 단위의 실제 간격을 제거했다. 기존 이동 벡터·엔진·원형 ㅇ 캐릭터는 유지한다. 다른 자모의 공통 SVG 템플릿과 다른 콘텐츠는 변경하지 않았다. [원본과 게임 글자 비교](http://127.0.0.1:5173/review/seong-font-comparison.html)는 별도 검토 자료이며 게임 UI에는 추가하지 않았다.

폰트 출처·라이선스·재생성·검사 근거는 [docs/seong-font.md](docs/seong-font.md), 공통 렌더링/충돌 구조는 [docs/vector-rendering.md](docs/vector-rendering.md)에 있다. 일반 한글 자동 획 분리·문장 분석·자동 퍼즐 생성은 후속 범위다.

## PWA 수동 확인

로컬 PWA 확인은 `pnpm.cmd pwa:web` 한 번으로 빌드 후 미리보기 서버를 실행한다. http://127.0.0.1:4173/ 을 Chrome 또는 Edge에서 열고 주소창의 설치 아이콘(또는 브라우저 메뉴의 앱 설치)을 사용한다. 종료는 Ctrl+C다. 소스 수정 후에는 서버를 종료하고 같은 명령을 다시 실행한다. 이 주소는 현재 PC 전용이며 스마트폰 설치 검증에는 HTTPS 주소가 필요하다.

1. build 후 preview:web을 실행하고 브라우저에서 연다.
2. 개발자 도구 Application에서 manifest와 활성 서비스 워커를 확인한다.
3. 첫 로딩·서비스 워커 활성화 후 오프라인으로 전환하고 새로고침해 첫 퍼즐을 확인한다. 진행 저장은 없으며 새로고침하면 처음부터 시작한다.
4. 화면 문구를 변경해 다시 빌드한 뒤 온라인으로 재접속한다. 새 버전 안내와 버튼 적용을 확인한다.
5. 캐시 저장소에서 오래된 precache 정리, 좁은 화면·가로 화면·키보드 포커스를 확인한다.
6. HTTPS 배포 후 Android 설치와 iOS 홈 화면 추가를 각각 검증한다. localhost 예외 외에는 HTTPS가 필요하다.

## 운영과 다음 단계

Cloudflare 정적 호스팅 후보: 빌드 명령 pnpm build, 출력 apps/web/dist, 런타임은 Node 24 계열로 맞춘다. 실제 배포 전 호스팅의 pnpm 지원과 HTTPS·manifest MIME·캐시 헤더를 확인한다. index.html·sw.js·manifest.webmanifest는 재검증하도록 하고 해시 자산에만 장기 캐시를 적용한다. 계정 연결·업로드·배포는 아직 수행하지 않았다.

Supabase는 원격 퍼즐 배포 후보이며 스키마·키·인증 정책은 아직 없다. 현재 환경 변수 없이 실행한다. 키가 필요해지면 자리표시자만 있는 .env.example을 추가하고 실제 비밀값은 Git에서 제외한다.

기획은 [docs/planning](docs/planning), 구조·기술 근거는 [docs/architecture.md](docs/architecture.md), 작업 기준은 [AGENTS.md](AGENTS.md), 실제 검사 상태는 [progress.md](progress.md)에 있다. PWA 다음 플랫폼 순서는 미정이며 기획의 웹·토스 동시 첫 출시 목표는 유지한다.
